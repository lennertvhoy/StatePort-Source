# ProjectState Template

> StateSpec template for project management and team coordination.

## Purpose

ProjectState helps a team track project goals, tasks, decisions, risks, and reminders.

## Planned state files

- `state/project.yaml` — project metadata and goals
- `state/tasks.yaml` — task list and owners
- `state/decisions.yaml` — decision log
- `state/risks.yaml` — risk register

## Allowed actions

- Read/write project state
- Propose task updates
- Create reminders
- Send status summaries (L3 approval required)
